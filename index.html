Help / Features

Core Gameplay

  • Open regular packs to collect cards across 7 main categories: Skills, Quests, Diaries, Combat Achievements, Bosses, Minigames, Clue Scrolls
  • Choose one card per pack to keep or dust duplicates/outdated tiers
  • Many cards have prerequisites — missing prereqs show the card as greyed-out/dashed and cannot be selected from packs
  • Quests require their listed prerequisite quests and skill levels (same restriction style as diaries/combat achievements)
  • Complete certain card types (Quests, Diaries, Combat Achievements, Bosses, Minigames, Clues) for extra dust
  • There is a Pack Cost display at the top of the screen to show how much you should be paying per pack. By default this is set to 1000gp and doubles for every 10% of total Completion. This base figure can be changed in the Settings menu. If staying in F2P for some time I recommend setting this to 500gp due to the lack of gp generation available (and for similar reasons I also suggest increasing the base Dust amounts for Common and Uncommon and switching back when going P2P).

Dust & Special Packs

  • Duplicates / outdated skill tiers → convert to dust when selected
  • Bosses, Minigames, and Clues auto-discard when their timer runs out (3 hours by default, set per card in the card data) — complete them before then for dust
  • Manual dust conversion: click complete on cards in your collection
  • Spend 10 dust on themed "Dust Packs" that guarantee 5 cards from one category
  • Dust values can be customized in Settings (rarity base + multipliers for Diaries / Clues / Bosses etc.)

Progression & Bonuses

  • Completing higher Combat Achievement tiers permanently increases Mythic drop rate in regular packs (+2.5% per tier, up to +15%)
  • Skills: only the highest tier per skill is kept — lower tiers become dust-convertible
  • Diaries & Combat Achievements: must complete tiers in order per area/tier set
  • My suggestion on progressing with overcapped skills is that XP is not barred from you, you simply cannot use or make things above your unlocked lvl. This prevents hard blocks (not being able to complete quests etc). The same goes for achievements, you can do the achievements but you can't hand-in for the rewards until you have the relevant unlock.

Smart Pack Weighting System

  • Packs use an intelligent weighting system to prioritize cards you'll actually want — focusing on your "next" tier of progress in each category.
  • How it works: The game detects the lowest incomplete rarity tier (e.g., if you've collected all Commons, it boosts Uncommons), this is called the focus rarity.
  • Items in the focus rarity get 2x weight (twice as likely).
  • Higher rarities get 0.5x weight (slightly less to avoid frustration since you can't select them yet).
  • Everything else is neutral (1x).
  • Dust packs use the same system, but targeted to one category for efficient farming.
  • Regular Pack structure: Always 6 Commons + 3 Uncommons + 1 Rare/Mythic slot.
  • Mythic chance starts at ~7.5% and increases +2.5% per completed Combat Achievement tier (up to 22.5% max).

This keeps opening packs exciting and rewarding without feeling random or unfair!

F2P Mode

  • Toggle in Settings → limits packs to Free-to-Play content only
  • Excludes most quests after Dragon Slayer I, all members skills above certain points, members bosses/minigames, higher clue tiers, all diaries, etc.
  • F2P is toggled on by default so the first 15 pack openings on new saves are always F2P. In addition only Commons and Uncommons are available to be picked. Rares and Mythics will not generate.

UI & Controls

  • Hover over quests / combat achievements → see requirements & rewards tooltip
  • Global rarity filter (top of screen) hides/shows cards by rarity
  • Tab between views (Quests / Diaries / Combat, Bosses / Minigames / Clues)
  • Export / Import save (JSON) — progress is saved automatically in browser

Collection Log

  • Click the Collection Log button (top bar) to open a full searchable table of ALL possible cards (469 with the default card data) across Skills, Quests, Diaries, Combat Achievements, Bosses, Minigames, and Clues
  • Filters & Search: Real-time search by name, dropdowns for Rarity and Type, F2P-only checkbox
  • Collected Status: Your owned/completed cards are highlighted green for easy progress tracking
  • Notes Column: Quick rewards/unlocks for each card
  • Clear Filters: Button resets all filters instantly
  • Perfect for planning next grinds, checking F2P viability, or seeing what Mythics you're missing!

Activity Log & Undo

  • Click the Activity Log button to see a chronological history of your actions (pack opens, keeps, dusts, completes, auto-discards, etc.)
  • Undo Last Action restores the exact previous game state — great if you misclicked a card or completed something by accident
  • Up to 25 undos are stored (and the visible log keeps the last ~150 entries)
  • Clear Log only clears the visible history; it does not reverse any progress
  • Undo also works across browser refreshes (stored in localStorage)

Card Data & Card Creator

  • Every card lives in a text reference section: Settings → Card Data has one box per card type (Skills, Quests, Diaries, Combat Achievements, Bosses, Minigames, Clue Scrolls). One card per line, columns separated by |.
  • Paste your own lines to add cards, or replace a whole section. Bad lines are skipped (the box tells you which) — they never break the game. Press Apply & reload to use your changes. Reset to default restores the original list.
  • Use Card Creator (top bar) to fill in a form and get a correctly formatted line, then copy it or add it straight to the section.
  • Your collection is stored by card name: if you rename or remove a card, it simply stops showing until the name exists again.

Install & Updates

  • When opened from its web address, BinderScape can be installed as an app (browser menu → Install / Add to Home Screen) and then works offline from its saved copy.
  • Nothing checks for updates in the background. Press Look for updates in Settings (next to the Data tab): it turns green and says Update now when a newer version exists. Your save, settings and card data are kept.
  • In a normal browser tab the check also runs once when the page opens.
